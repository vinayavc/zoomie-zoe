Zoomie Zoe: icon and promo-tile maker

Draws Zoe's face procedurally (no image files) with the game's own palette and helpers, then offers PNG downloads. ES modules need a web server: from the project root run python3 -m http.server 8743 --bind 127.0.0.1 and open http://127.0.0.1:8743/store/tools/icon-maker.html. Copy the 16/32/48/128 PNGs and the PWA icons (180, 192, 512, maskable-512) to src/icons/ and the promo tile to store/promo-440x280.png.
